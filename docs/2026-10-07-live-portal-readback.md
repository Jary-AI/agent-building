# Live Portal Readback and Campaign Selection

**Date:** 2026-10-07

## Observation

The live Jary Portal GTM Programs surface showed five records: four active programs with enrolment open and one draft program. The active records were KM Bundled Pack, ITSM Replacement: Modern Service Operations, Partner Account Mapping Sprint and New Partner First-Win Reward. TEC Workshop for Agentic AI was still a draft with 4/6 readiness gates.

## Decision

Do not create a new generic partner campaign. Use the existing **Partner Account Mapping Sprint** as the first execution surface and express the Partner Fit Clinic as its next action.

## Why this matters

The agent must read the operating system before proposing more campaigns. Existing program state, readiness gates, enrolment and asset ownership are higher-value signals than a new copy concept. Campaign design should reduce fragmentation and advance an existing commercial motion.

## Execution boundary

- Read the Portal and HubSpot before campaign design.
- Start with one program, one cohort and one measurable result.
- Keep TEC Workshop in draft until the missing readiness evidence is complete.
- Do not enroll companies, edit programs, send outreach, publish content or sync CRM during the planning pass.

## Reusable lesson

```text
live program inventory
  -> choose the program with the clearest result path
  -> inspect readiness and cohort
  -> design the smallest next action inside that program
  -> run draft-only QA
  -> approve one external action
  -> read the result before adding volume
```
